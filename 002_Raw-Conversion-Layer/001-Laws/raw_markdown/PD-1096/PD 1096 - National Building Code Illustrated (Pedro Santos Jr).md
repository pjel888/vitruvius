## RULE 1

General Provisions

![image 12](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile12.png)

###### PURPOSE OF THE CODE

▪ To provide a framework of minimum standards

and requirements for all buildings in order to regulate their location, design, quality of materials,

construction, and use.

![image 17](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile17.png)

###### SCOPE OF APPLICATION

▪ The National Building Code (NBC) applies to the

design, location, siting, construction, alteration, repair, conversion, use, occupancy, maintenance,

moving, demolition of and addition to public and

private buildings, except traditional dwellings and BP 220 projects.

##### Definition of terms

![image 26](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile26.png)

## Construction

All on-site work done from site preparation, excavation,

foundation, assembly of all the components and installation of utilities and equipment of

buildings/structure

![image 31](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile31.png)

## Addition

###### Any new construction whichincreases the height or area

of an existing building/structure

![image 36](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile36.png)

## Alteration

Construction in a building/ structure involving changes in

the materials used, partitioning, location/ size of openings, structural parts, existing utilities and equipment but does

not increase the overall area thereof.

![image 41](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile41.png)

## Renovation

Any physical change made on a building/ structure to

increase its value, utility and/ or to improve its aesthetic quality

![image 46](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile46.png)

## Conversion

A change in the use or occupancy of a building/ structure

or any portion/s thereof which has different requirements

![image 51](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile51.png)

## Repair

Remedial work done on any damaged or deteriorated

portion/s of a building/structure to restore its original condition

![image 56](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile56.png)

## Demolition

The systematic dismantling or destruction of a building/

structure, in whole or in part

![image 61](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile61.png)

## Ancillary building/structure

A secondary building/ structure located within the same

premises, the use of which is incidental to that of the main building/structure

## RULE 3

Permits

![image 116](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile116.png)

###### BUILDING PERMIT

▪ A written authorization granted by the Building

Official to an applicant allowing him to proceed with construction after plans, specifications and

other pertinent documents have been found to be

in conformity with the Code

![image 121](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile121.png)

###### WHEN IS A PERMIT REQUIRED?

▪ Before constructing, altering, repairing, converting,

moving, adding to, demolishing a building.

![image 126](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile126.png)

###### BUILDING PERMIT EXEMPTIONS

- ▪ Minor constructions
- ▪ Repair works


![image 131](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile131.png)

- ▪ Minor structures 6sqm. or less detached from other buildings, for private use only. (Example: sheds, poultry houses, greenhouses)
- ▪ Open terraces or patios not exceeding 20sqm.


![image 136](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile136.png)

- ▪ Window grilles
- ▪ Garden pools 500mm deep or shallower
- ▪ Garden masonry walls not exceeding 1.20m in height


![image 141](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile141.png)

- REPAIRS
- ▪ Not involving structural members
- ▪ Of non-load bearing partition walls
- ▪ Not involving addition or alteration
- ▪ Of doors, windows, floors, fences and walls
- ▪ Of plumbing fixtures


![image 146](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile146.png)

- ▪ Application forms
- ▪ If lot is owned,
- ▪ OCT or TCT
- ▪ Tax declaration
- ▪ Current real property tax receipt


![image 151](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile151.png)

- ▪ If lot is NOT owned,
- ▪ Contract of Lease or Deed of Absolute Sale in place of TCT
- ▪ Five sets of plans and specs, signed and sealed by various professionals


![image 156](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile156.png)

- ISSUANCE OF PERMITS
- ▪ 15 days from payment of fees


![image 161](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile161.png)

- ▪ Article 1723 of the Civil Code states that the engineer or architect who drew up the plans and specifications is liable for 15 years from completion of the building should it collapse due to defects in the plans or the ground.


![image 166](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile166.png)

###### ▪ In case the building collapses due to defects inconstruction or the use of inferior materials, thecontractor, along with the construction supervisor,shall be liable.

![image 171](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile171.png)

###### EXPIRATION OF PERMITS

- ▪ Construction does not commence within 1 year from date of issue
- ▪ Construction does not resume 120 days after suspension or abandonment of work


![image 176](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile176.png)

NON-ISSUANCE, SUSPENSION,

REVOCATION

- ▪ Errors in plans and specs
- ▪ Incorrect or inaccurate data declared
- ▪ Non-compliance with the Code


![image 181](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile181.png)

###### INSPECTION + SUPERVISION

- ▪ The owner of the building must engage the services of a licensed architect or civil engineer to undertake the full-time inspection and supervision of the construction.

## RULE 5

Fire Zones

![image 221](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile221.png)

###### FIRE ZONE

▪ An area within which only certain types of

construction are allowed, based on their occupancy, type of construction, and resistance to

fire

![image 226](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile226.png)

###### FIRE ZONE DESIGNATIONS

###### 1. Non-fire restricted zones

▪ All types of construction allowed

###### 2. Fire restrictive zones

▪ Type I construction NOT allowed

###### 3. Highly fire restrictive zones

- ▪ Types I, II, and III NOT allowed


![image 231](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile231.png)

###### BUILDINGS IN MULTIPLE FIRE ZONES

- ▪ Shall be considered as part of the more restrictive zone if more than 1/3 of its total floor area is in that zone

#### Location on property

![image 466](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile466.png)

###### RIGHT OF WAY

▪ No building shall be constructed unless it adjoins

or has direct access to a public space, yard, or street on at least one of its sides.

![image 471](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile471.png)

###### EAVES OVER WINDOWS

▪ Eaves over required windows shall at least be

750mm from the side and rear property lines.

- ▪ A fireproof barrier used to prevent the spread of fire between or through buildings
- ▪ Why are firewalls important? Because when they are built, the building or part of the building extends into the setbacks.

###### BUILDING BULK

- ▪ A volume quantity
- ▪ In the simplest sense,
- ▪ Building bulk = Footprint x Height
- ▪ However, the Code prescribes several different methods for determining this quantity


![image 732](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile732.png)

- METHOD 1: AMBF PROJECTION
- ▪ Determine the AMBF
- ▪ Determine the BHL (in meters)
- ▪ AMBF x BHL = Building bulk


![image 737](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile737.png)

###### METHOD 2: FLAR

- ▪ FLAR : Floor to lot area ratio
- ▪ Total floor area / lot area
- ▪ For example, a FLAR designation of 1.50 means that a lot measuring 100sqm may accommodate a building whose total floor area is 150sqm.
- ▪ In a way, FLAR tells us how many lots can fit inside the building.


![image 742](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile742.png)

![image 747](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile747.png)

![image 752](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile752.png)

- METHOD 2: FLAR
- ▪ Building bulk = Footprint x Height
- ▪ To get footprint:
- ▪ FLAR x TLA = Total floor area
- ▪ Total floor area/Number of storeys = Footprint


▪ Hence, building bulk is equal to:

###### ▪ [(FLAR x TLA)/number of storeys] x BHL

![image 757](PD 1096 - National Building Code Illustrated (Pedro Santos Jr)_images/imageFile757.png)

###### METHOD 3: AMVB

- 1. AMBF x BHL = initial AMVB (“prism”)
- 2. Superimpose the angular plane originating from the RROW onto the “prism”

▪ Angular plane: a plane originating from the RROW that establishes the outer limit for walls and building projections.

- 3. Use the angular plane to reduce the volume of the prism. This is the AMVB.
