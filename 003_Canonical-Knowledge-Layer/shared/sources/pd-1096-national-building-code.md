# National Building Code of the Philippines

## Overview

Presidential Decree No. 1096 establishes the National Building Code of the Philippines. It provides the legal framework governing the planning, design, construction, occupancy, and maintenance of buildings and structures within the country.

## Source Identity

- Type: Presidential Decree
- Jurisdiction: Philippines
- Authority Level: Primary
- Governing Body: National Government
- Common Reference: PD 1096

## Coverage

The code governs:

- building design and construction standards
- occupancy classification
- fire-resistive requirements
- structural safety
- sanitation and health requirements
- light and ventilation
- land use controls related to buildings
- administrative procedures and permits

## Key Canonical Points

- Establishes minimum standards for safe and habitable structures
- Defines occupancy classifications and corresponding requirements
- Provides rules for setbacks, building height, and site development
- Requires compliance with structural, sanitary, and fire safety provisions
- Delegates detailed technical implementation to the Implementing Rules and Regulations (IRR)
