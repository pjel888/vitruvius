# Audit — Bootstrap artifact promotion

## Reality check
The system can now bootstrap rules, concepts, and relationships for non-laws families, but the generated rule overlay will grow indefinitely unless there is a deliberate promotion surface.

## Safe scope
- promote generated canonical rules only
- identify rules by exact name
- avoid automatic promotion of every generated rule
- keep the overlay file as the temporary staging layer until a reviewed promotion command is run
