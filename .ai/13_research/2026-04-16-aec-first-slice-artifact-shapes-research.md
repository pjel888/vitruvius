# Research — AEC First-Slice Artifact Shapes

## Purpose
Freeze the minimum JSON/manifest shapes for the future first-slice runtime outputs before coding begins.

## Conclusion
The future implementation phase needs explicit output-shape contracts for:
- boundary DTO artifacts
- ECS snapshot artifacts
- spatial fact bundles
- verification verdict artifacts
- promotion/audit manifests

Without those shapes, the later coding phase will improvise file formats and create avoidable churn.
