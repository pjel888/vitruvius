# Research — AEC First-Slice Validation Template

## Purpose
Freeze the exact structure of the future bounded-slice validation report so the implementation phase does not improvise its final proof artifact.

## Conclusion
A bounded first-slice validation report should always include:
- baseline and commit used
- test command groups and outcomes
- fixture roots checked
- artifact roots checked
- scope-drift review
- explicit G10 closure verdict

This improves later proof quality but does not close G10.
