# Research — AEC First-Slice Session Packet

## Purpose
Create a single-session operator packet for the future bounded first-slice execution so the implementation session starts from a bounded, repeatable checklist instead of ad hoc navigation.

## Conclusion
A future implementation session should begin from one compact packet that summarizes:
- baseline to use
- docs to open first
- commands to run
- artifact roots to inspect
- stop conditions to watch
- final evidence to collect

This improves operator discipline but does not close G10.
